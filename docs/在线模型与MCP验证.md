## 运行与边界

完整新环境可运行 `python -m pip install -e ".[raganything]"`。本机验收使用共享已有依赖的项目虚拟环境，并未重新安装所有可选依赖；MinerU 原始 PDF 解析、本次未重建的全部 PDF 图谱和长期并发压力不在验收范围内。

测试使用本地现有 Chroma、图片和一条真实 PDF 记录，证明链路可运行，不代表整体物种识别或事实准确率。
首次未命中的图谱查询可能较慢；验收使用 180 秒模型/查询超时、210 秒 MCP 超时。后续请求可复用 LightRAG 缓存。

可重跑 `scripts/verify_online_stack.py`。`--only-failed` 复用同一模型和地址下已成功的独立工具检查，并重新执行全部工作流场景；报告保留各次实测结果。
