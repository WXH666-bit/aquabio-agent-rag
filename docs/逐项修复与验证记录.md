## 验证方式

- `python -m unittest discover -s tests -v`：61 项全部通过，覆盖 API、检索、会话、任务取消、索引故障注入、BM25缓存和真实数据验收。
- 构建 wheel 后在临时虚拟环境（共享本机已有依赖）安装，验证三个安装后的 CLI 的 `--help`。未重新下载全部模型及依赖。
- `python scripts/evaluate_retrieval.py --output docs/retrieval-baseline.json`：真实向量检索；8例 Hit@6=100%，MRR=0.9，Precision@6=68.75%。
- 评测中 caption 是固定的视觉描述，追问带已解析的物种 ID；这些分数不代表视觉模型识别准确率、完整会话准确率或答案事实准确率。
- 当前中文海马查询的首个正确结果排名第五，相关性仍有优化空间；评测用于后续比较，不能用小样本推断整体质量。

## 兼容性与运行边界

已有合法的小写会话 ID 保持原路径。过去使用空格等字符创建的 CLI 会话，应使用其原先保存时规范化后的 ID 访问；现在不再进行有损转换。
取消为协作式取消，不强行中断已经发出的模型/HTTP请求；提交完成后的数据不会撤回。
后台任务仍应使用单个 API worker；多进程共享任务、跨重启恢复需要独立任务存储。
后续已补齐付费在线模型与真实 MCP 验收，详情见[在线模型与 MCP 验证](在线模型与MCP验证.md)；最新离线回归为 68 项通过。

索引 manifest 中的 `previous_collection_name` 指向前一集合。回滚前停止写入，确认目标集合存在，并恢复匹配的旧 manifest；旧集合和模型版本必须对应。历史集合保留是为了可回滚，应在确认不再需要后单独清理。
